ITBODY: 카카오 회원 연결 및 다중 센터 지원

1. 회원별 초대 링크: 관리자가 발급해 회원에게 전달. 24시간 유효, 일회용.
2. 일반 주소로 로그인: 카카오 인증 → 센터 선택 → 이름/휴대폰 전달 동의 → 연결 요청.
3. 관리자: 회원 목록 상단의 카카오 회원 연결 요청에서 기존 회원을 선택하고 본인 확인 후 승인/거절.
4. 회원: 승인 상태 새로고침 → 연결된 센터 입장. 여러 센터 연결 시 로그인 후 센터 선택.
5. 기존 회원의 이메일 계정 UID와 PT 기록은 변경하지 않음. 카카오 연결은 portalUid와 memberAccounts/{uid}/centers/{centerId}에 별도 저장.
6. 이전 Kakao 연결은 실제 UID/회원/센터 일치 확인 후 첫 로그인 때 자동으로 새 구조로 전환.
7. 승인 전에는 센터 회원 기록 접근 불가. 서버 소유 연결 문서와 선택 센터 토큰을 Firestore Rules에서 검증.
8. 센터 검색은 인증 후 이름/사업장 주소만 반환. centers 문서에 name 필요. memberRegistrationEnabled=false인 센터는 가입 검색 및 요청에서 제외.
9. 하나의 카카오 계정에는 같은 센터의 기존 회원 한 명만 연결. 이미 다른 카카오 계정에 연결된 회원의 연결 교체는 허용하지 않음.
10. 이번 변경은 AI Studio 서버/클라이언트 및 named Firestore Rules. 기존 Firebase Functions 두 개 재배포는 불필요. firebase.json의 database 지정 확인.

검증: 타입 검사 및 배포 빌드 통과. 기존 보안 113 + 다중 센터 Rules 51 + 서버 67 + AuthContext 5 시나리오. Auth/Kakao는 모의 서비스, DB는 로컬 에뮬레이터 사용. 실제 카카오 로그인/관리자 승인은 테스트 회원으로 확인 필요.
